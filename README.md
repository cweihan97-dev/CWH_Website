# Chua Wei Han — Portfolio Website

A lightweight, responsive static portfolio website built with plain HTML, CSS, and JavaScript. It does not require a paid plugin, backend, build step, or framework.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — small-screen navigation and current footer year

## Before publishing

1. Open `index.html`.
2. Replace the contact placeholder with your real professional email and LinkedIn URL.
3. Add a public résumé PDF if desired. Put it in a folder such as `assets/` and uncomment/edit the résumé link in the contact section.
4. Add approved project screenshots, store links, and accurate descriptions of your personal contributions.
5. Check all text and links before sending the site to interviewers.

The page intentionally avoids invented project-specific responsibilities, metrics, testimonials, and links. Project cards currently include only known title/platform information and general experience context.

## Publish with GitHub Pages

1. Create a GitHub repository. For a user site, name it `YOUR-USERNAME.github.io`; alternatively, use any repository for a project site.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish, then open the URL shown in Settings → Pages.

No payment or third-party plugin is required for GitHub Pages hosting.

## Notes

- Google Fonts is used for typography. If you prefer not to load external resources, remove the `@import` line at the top of `styles.css`; the site will fall back to system fonts.
- Use only screenshots and materials you have permission to publish.
- If you use a project repository rather than a `YOUR-USERNAME.github.io` repository, the site URL will usually include the repository name.
